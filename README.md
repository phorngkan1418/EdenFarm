# Eden Farm Order Manager

A polished frontend-only farm order management application built with React, TypeScript, Zustand, ExcelJS, and localStorage.

## Features

- Professional dashboard, order management, customer directory, and reports
- Add, edit, and delete customer orders
- Multiple products per order with automatic totals
- Paid, unpaid, and partial payment tracking
- Today, week, month, specific-day, and custom-range filters
- Search customers, phone numbers, products, notes, and payment status
- Excel import, append import, replace import, and filtered export
- Dates displayed and exported as DD/MM/YYYY
- Automatic localStorage persistence
- Responsive layout for desktop, tablet, Android, and iPhone 11
- Mobile order cards instead of a wide table

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite, normally `http://localhost:5173`.

## Build

```bash
npm run build
```

## Data safety

Records are stored in the current browser and device. Export an Excel backup regularly. Clearing browser data removes local records.
